# ADVB_OPT_LIST_1_2025

This repository shows analytics, segmentation and building different models for the project "Optimization of customer lists for communication based on contact history"

There are two targets in the dataset: the first target is a response to communication by email, the second target is a response to communication by phone.

Danil Popov was engaged in analytics - the laptop is called azalyz_data.

Yulia Morozova was engaged in segmentation - the laptop is called segmentation. The following methods were tried: kmeans, dbscan, agglomerative.

Platon Bolotin was engaged in models - laptops are called models that are used. The following methods were tried: LogisticRegression, Decision Tree, Random Forest, CatBoost, XGBoost, LightGBM.
